Welcome to Achievement Unlocked, created by Olivia Taylor.

This is a web application designed to showcase my steam achievements and game progress. The application includes features such as a library of games (each having their own page),
a wishlist for future purchases, and a gallery to my screenshots. The site is built using ASP.NET Web Forms and includes a master page for consistent layout across all pages.

-------------------------------------------------------------

How to use:

1. Clone the repository to your local machine.
2. Open the solution in Visual Studio.
3. Build the solution to restore any missing packages.
4. Run the application using IIS Express or your preferred web server.
5. Navigate to the home page to view information about the website.
6. Use the navigation bar to access different sections of the site, including the library, wishlist, and gallery.
7. Each game in the library has its own page with detailed information about achievements and progress - click them to see!
8. The wishlist page allows you to view games I am interested in purchasing in the future.
